# Drafter's brand

![Drafter: screenplays and stage plays, written in plain text](og-image.svg)

## The mark

A tile split by a line: plain-text source on the left, the formatted script on the right, which is what Drafter does. The bars on the right sit where a script puts them, the short one indented like a character cue. The tile blends the first three revision-page colors, blue, pink, and yellow.

Use `mark.svg` from 24 px up and `favicon.svg` below that; the favicon is drawn on a 32-pixel grid so its bars stay sharp at 16 and 32 px. Keep clear space around the mark of at least a quarter of its width. Don't rotate it, recolor it, or set it on a busy background.

## The wordmark

"drafter", lowercase, in Inter Tight ExtraBold, tracked tight. It's white on dark backgrounds (`logo-dark.svg`) and ink on light ones (`logo-light.svg`), and never any other color.

## Color

The palette is the screenwriter's own: the colors a production script's revised pages are printed on, in the order they're used.

| Name | Hex | | Name | Hex |
|---|---|---|---|---|
| White | `#FFFFFF` | | Goldenrod | `#E5B04A` |
| Blue | `#8DB8E8` | | Buff | `#EBD7A9` |
| Pink | `#F5A9C0` | | Salmon | `#F49C84` |
| Yellow | `#F6E07A` | | Cherry | `#D9466B` |
| Green | `#9BD3A0` | | Ink | `#111216` |

Backgrounds are near-black (`#0F1013`, with `#121318` to `#0B0C0F` gradients); secondary text is `#AEB4C0`.

## Type

- **Inter Tight** (SemiBold 600 and ExtraBold 800) for the wordmark, headlines, and interface.
- **Courier Prime** for anything that is script: the source pane, the pages, and the PDF.

## Rebuilding

Every file is generated by [`build.mjs`](build.mjs), which converts each letter to an outline so the SVGs render the same everywhere without fonts, GitHub included. From the repository root, after `pnpm install`:

```sh
node brand/build.mjs
```

It needs `rsvg-convert` (librsvg) on the path for the PNGs: `brew install librsvg` on macOS, `apt install librsvg2-bin` on Debian and Ubuntu.
