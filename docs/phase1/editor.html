SavedEsc leaves focus

The editor is drawn at desktop size and shrunk to fit. Turn your phone sideways, or pinch to zoom, for a closer look.

  • Focus mode hides the toolbar, tabs, status bar, and the Script pane, and sets the source on a page in the middle of the screen. Esc, or the same shortcut, brings everything back. A small saved or unsaved marker stays in the corner, because Drafter promises unsaved changes are always visible.
  • Typewriter scrolling is a separate switch in the Source pane's bar and the command palette. It works with or without focus mode, and Drafter remembers both settings.
  • Not in Phase 1: the earlier mockup's Read aloud button (Phase 4) and Reference search (Phase 2). The tabs for later phases appear when they exist rather than sitting there dimmed.
