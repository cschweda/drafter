# Threads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tag scenes and novel passages with plot threads and see them as lanes along the work (v0.29.0).

**Architecture:** A script's threads are `[[Thread: A, B]]` notes in each scene (read alongside the old `[[Storyline: …]]`), with names and colors in the settings block; a novel's are a `threads` list in each passage's facts, with names and colors beside them. `@drafter/outline` turns either into one `Lanes` shape (`lanesOf`), which one Vue view draws as an ARIA grid in the Outline tab's new **Lanes** view.

**Tech Stack:** TypeScript, Vitest (+ fast-check), Vue 3 / Nuxt 4 with @nuxt/ui, Playwright + axe, pnpm workspace.

**Spec:** `docs/drafter-threads-design.md` (approved 2026-11-26). Read it before any task; section numbers below are its.

## Global Constraints

- Branch `threads` from `origin/staging` after v0.28.0 is merged there; own worktree; `pnpm install` first. Own `E2E_PORT` (4183).
- Words (exact): "Threads", "Threads…", "New thread", "No thread", "Lanes", "Tree", "Rename thread…", "Name…", "Color…", "Remove from every scene…" (novel: "Remove from every passage…"), "Show as table", "No threads yet. Add one from a scene's menu: Threads…", novel: "No threads yet. Add one from a chapter's or section's menu: Threads…", "Renamed thread {a} to {b} in {n} scenes." (novel: "passages"), "{b} is already a thread. Merge {a} into it?", "A Markdown document has no scenes.", the Atlas's "Setups and payoffs".
- File format: write `[[Thread: …]]`; read `Thread` and `Storyline` alike, forever. Settings block key `threads`: `{ "<normalizeLabel(label)>": { "name"?: string, "color"?: SceneColor } }`. Novel facts: `nodes[id].threads: string[]`, book-level `novel.threads` map, same shape.
- Labels: trimmed, 1–40 UTF-16 units, no `,` `[[` `]]` or line break; ≤ 12 per unit; case-insensitive identity via `normalizeLabel`, shown as first typed. Names ≤ 80 units. Longer is cut when read.
- Colors: only `SCENE_COLORS` (red, orange, yellow, green, teal, blue, purple, pink, gray). An unchosen color is shown, never written: the n-th thread by first appearance gets `SCENE_COLORS[n % 9]`, skipping colors chosen by other threads.
- Budget: `lanesOf` + unit building ≤ 10 ms for 120 pages / 120,000 words, proven by growth (`packages/outline/test/scaling.ts` pattern: n and 4n, growth under 8). No long task while typing with Lanes shown (compute only while held, after typing pauses, as the strip does).
- Clean room; no network; nothing on the writing screen nags. Read-only states make every edit `aria-disabled` with the reason (as Scene details).
- Every edit is one undo step. Gates per `docs/DEVELOPMENT.md` before the PR; CHANGELOG `[Unreleased]` in every push.

## Review Focus

1. **A scene with both `[[Storyline: A]]` and `[[Thread: B]]` notes**, then edited with Threads…: expect one `[[Thread: A, B]]` note (order kept), both old notes gone, one undo restores both. (Task 1, Task 2 tests.)
2. **Labels that differ only by case or width** (`a` vs `A`, `Ａ`): one thread, shown as first typed; rename `A`→`a` is a rename, not a merge prompt. (Task 2.)
3. **A novel chapter renamed or moved** after tagging: its threads and the book's thread names follow (`carryFacts`), none orphaned. (Task 3.)
4. **A locked script or a viewed draft:** Threads…, rename, color, remove are disabled with the reason; the lanes still show. (Task 6 e2e.)
5. **Hostile labels and names** (300-char label, 50 labels on one scene, RTL text with joiners, `]]` typed into New thread, `__proto__` as a label): cut or refused, never a broken note, never a prototype write. (Task 2, Task 3 tests; a trap document in Task 9.)

```ts
interface LaneUnit { id: string; label: string; heading: string; from: number; length: number; threads: string[]; inherited?: boolean }
interface Lanes { units: LaneUnit[]; threads: { key: string; label: string }[]; total: number; unit: 'pages' | 'words' | 'lines' }
function lanesOf(units: LaneUnit[], unit: Lanes['unit']): Lanes
function scriptUnits(index: SceneIndex, perPage: number | null): { units: LaneUnit[]; unit: 'pages' | 'lines' }
function novelUnits(tree: NovelTree, facts: NovelFacts): LaneUnit[]   // apps/web/app/threads/novel-units.ts
```

`label` is the scene number (written or counted) or the passage's short title; `length` is eighths of a page, printed lines, or words.
